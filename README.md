📈 Learning Journey

🔹 Basic Problems

Sum of Array → Calculate the total sum of all elements.

Count of Odd Numbers → Find how many elements are odd.

Maximum and Minimum Element → Identify the largest and smallest elements.

Reverse an Array → Reverse the order of elements in place.

Search an Element (Linear Search) → Find an element’s index manually.

🔸 Intermediate Problems

Second Largest Element → Find the second biggest value without sorting.

Remove Duplicates from Sorted Array → Optimize space usage while removing duplicates.

Rotate Array → Shift array elements by a given number of positions.

Move Zeros to End → Rearrange elements while maintaining order.

Union & Intersection of Two Arrays → Work with multiple array datasets.
